# Migrations SQL

Chaque changement de structure de la base est un fichier SQL daté, rangé ici :
`20261115120000_creer_tables.sql`, `20261116090000_regles_rls.sql`, etc.

Pourquoi : le dépôt Git devient la source de vérité. Même sans sauvegarde,
on peut recréer la base à l'identique (sans les données) sur un projet neuf.

Ce dossier se remplit à l'étape 2.
